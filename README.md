# 🖥️ C# Windows Forms Görev / Proje Uygulaması

Bu depo, akademik proje görevleri kapsamında geliştirilen C# Windows Forms (`WinForms`) uygulamasını içermektedir. Proje, temel masaüstü programlama mantığını ve form bileşenlerinin kullanımını pekiştirmek amacıyla hazırlanmıştır.

## 📌 Proje Özeti
*(Bu kısma hocanın verdiği görevin tam olarak ne yaptığını 1-2 cümleyle yazabilirsin. Örnek: "Bu uygulama, kullanıcıdan alınan verileri işleyerek ekrana listeleyen basit bir form arayüzüdür.")*

## 🛠️ Kullanılan Teknolojiler
* **Programlama Dili:** C#
* **Platform:** .NET Framework / Windows Forms
* **IDE:** Microsoft Visual Studio
* **Sürüm Kontrolü:** Git & GitHub

## 🚀 Kurulum ve Çalıştırma
Projeyi kendi yerel ortamınızda (Localhost) çalıştırmak için aşağıdaki adımları izleyebilirsiniz:

1. Bu depoyu bilgisayarınıza klonlayın:
`git clone https://github.com/emirhansartik/Csharp-WinForms-Task.git`

2. Klonladığınız klasörün içindeki `WindowsFormsApp1.sln` (Solution) dosyasına çift tıklayarak projeyi Visual Studio'da açın.

3. Üst menüden **Start (F5)** butonuna basarak uygulamayı derleyip çalıştırabilirsiniz.

## 📂 Proje Yapısı
* `WindowsFormsApp1/` - Ana uygulama kaynak kodlarını, form tasarımlarını ve arka plan (Code-Behind) işlemlerini barındıran klasör.
* `.gitignore` - Sürüm kontrolüne dahil edilmemesi gereken sistem ve derleme dosyalarını (bin, obj vb.) filtreleyen yapılandırma dosyası.
